# Student Performance Analyzer

Un proiect Python complet pentru analiza performantei academice a studentilor, cu vizualizari grafice profesionale și statistici detaliate.
## Caracteristici Principale

- ✅ **Citire date din CSV** - Import și procesare automată
- ✅ **Analiza statistica completa** - Medie, mediana, min, max, procente
- ✅ **Identificare restantieri** - Detectare studenti cu note sub 5
- ✅ **Clasament studenti** - Top studenti
- ✅ **Vizualizari interactive** - 4 tipuri de grafice profesionale
- ✅ **OOP Design** - Cod modular și reutilizabil
